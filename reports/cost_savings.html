How to read this

"Savings (auto vs this)" answers "if I had pinned to this single model instead of letting the gateway route, what would the same workload have cost?"

  • Negative % (green) = auto is cheaper.
  • Positive % (red) = auto is more expensive than this target.
  • Quality is held constant within each workload, so cost deltas are apples-to-apples.

Other eval runs in eval/results/ are single-target (auto only), so no comparison is possible there. To add another row, run the multi-target eval harness against the same workload with a different --target.
